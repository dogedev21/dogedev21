# 🥇 Featured Repos

## - SAMS Nexus
**SAMS Nexus** is a privately hosted Discord operations and personnel management platform built with Node.js, discord.js, and MariaDB. It centralizes FTO requests, promotions, LOA/ROA management, events, analytics, role automation, and administrative workflows into a modular system designed for real-world community operations. 
See the full public facing README [here](https://github.com/dogedev21/SAMS-Nexus-Public)

## - [doge_jobmail](https://github.com/dogedev21/doge_jobmail)
**doge_jobmail** is a lightweight FiveM resource for QBCore servers that integrates `qb-management` with LB Phone to automatically send in-game emails when players are hired, fired, promoted, or demoted. Built in Lua, it adds a small quality-of-life layer to job management while remaining simple to customize and adapt for other server setups.
