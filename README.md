# 🥇 Featured Projects

## SAMS Nexus

**SAMS Nexus** is a privately hosted Discord operations and personnel management platform built with **Node.js, Discord.js, and MariaDB**.

It brings several community management workflows into one system, including FTO requests, promotions, LOA/ROA management, events, analytics, role automation, and administrative tools. The project is designed around keeping those workflows organized, automated, and easy to manage.

The production source is private, but you can check out the public-facing project and documentation [here](https://github.com/dogedev21/SAMS-Nexus-Public).

## [doge_jobmail](https://github.com/dogedev21/doge_jobmail)

**doge_jobmail** is a lightweight FiveM resource for **QBCore** servers that connects `qb-management` with **LB Phone**.

It automatically sends in-game emails when players are hired, fired, promoted, or demoted, adding a simple quality-of-life improvement to job management without overcomplicating the setup.

Built in **Lua** and designed to be easy to modify for different servers and workflows.
